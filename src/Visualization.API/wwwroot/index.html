Power BI Integration

Configure Power BI settings in appsettings.json to embed reports.

Required settings:

  • TenantId - Azure AD Tenant ID
  • ClientId - Azure AD App Registration Client ID
  • ClientSecret - Azure AD App Secret
  • WorkspaceId - Power BI Workspace ID
  • GeospatialReportId - Report ID for geospatial visualization
  • TemporalReportId - Report ID for temporal visualization
